Read JSON from stdin and print the value at a JSON Pointer such as /a/b.

## Install

```bash
git clone https://github.com/theworker02/jsonptrget.git
cd jsonptrget
npm install -g .
```

Package version: **1.00** (`1.0.0`).

## Usage

```bash
jsonptrget /a/b < data.json
```
