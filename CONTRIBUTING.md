# Contributing

Default branch is `main`. Open issues and pull requests against `main`.

1. Fork and clone the repository.
2. Create a focused branch from `main`.
3. Add or update tests under `test/` and run `npm test`.
4. Keep the CLI Node.js-only; do not add runtime dependencies.

Commit messages should follow `feat|fix|docs|chore|refactor|test|ci: summary`.
