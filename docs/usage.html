jsonptrget

Every flag, subcommand, and exit code. Same examples as the README.

Synopsis

jsonptrget [options] <pointer>
Tip: jsonptrget --help prints this text in the terminal. jsonptrget --version prints 1.0.0.

Flags and arguments

Flag / argumentMeaning
-h, --helpPrint detailed usage and exit 0.
-v, --versionPrint 1.0.0 and exit 0.
<pointer>JSON Pointer starting with /. Empty pointer is the whole document. ~0 and ~1 unescaping is supported.

Exit codes

CodeMeaning
0Pointer resolved.
1Missing pointer, invalid JSON, or missing path.

Configuration

JSON is read from stdin. Strings print raw; other values print JSON.stringify. Missing paths error.

Worked examples

Success path

echo '{"a":{"b":[false, {"x/y": 9}]}}' | jsonptrget /a/b/1/x~1y

Prints `9`.

Failure path

echo '{"a":1}' | jsonptrget /missing
missing missing

Exit code is 1.
