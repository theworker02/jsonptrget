Typed RFC 6901 JSON Pointer utilities plus a focused Node.js CLI.

JSR @theworker02/jsonptrget ESM MIT Node.js CLI ≥ 18

Overview

jsonptrget implements RFC 6901 pointer traversal with a small documented ESM package surface and a separate repository CLI.

Public distribution now lives on @theworker02/jsonptrget on JSR.

Package API

import { getPointer, hasPointer, setPointer } from "jsr:@theworker02/jsonptrget";

const doc = { app: { name: "Nex" } };
console.log(getPointer(doc, "/app/name"));
console.log(hasPointer(doc, "/app/version"));
setPointer(doc, "/app/version", 2);

Also exports tokensOf, escapeToken, unescapeToken, parseJsonValue, formatValue, and PACKAGE.

CLI

The repository CLI remains available for Node.js 18+ users.

git clone https://github.com/theworker02/jsonptrget.git
cd jsonptrget
node src/cli.js /name package.json
