jsonptrget

Read JSON from stdin and print the value at a pointer such as /a/b.

1.00 / 1.0.0 branch main MIT Node.js >= 18

Overview

jq is powerful but heavy for one lookup. jsonptrget implements JSON Pointer (RFC 6901) for a single get.

Script authors extracting one field from an API body or a lockfile without a full JSON query language.

Install

Install globally from Git, or run with Node from a clone. There are no extra dependencies.

npm install -g git+https://github.com/theworker02/jsonptrget.git
jsonptrget --help
node src/cli.js --help

Usage

Synopsis: jsonptrget [options] <pointer>

See the full CLI reference for every flag, exit code, and example.

jsonptrget 1.00 (1.0.0)

Usage:
  jsonptrget <pointer> < data.json
  jsonptrget --help
  jsonptrget --version

JSON Pointer (RFC 6901):
  /a/b       object walk
  /items/0   array index
  ~1         escaped slash
  ~0         escaped tilde
  (empty)    whole document

Options:
  -h, --help       Show this help
  -v, --version    Print 1.0.0

Examples:
  jsonptrget /name < pkg.json
  echo '{"a":{"b":1}}' | jsonptrget /a/b

Examples

Success

echo '{"a":{"b":[false, {"x/y": 9}]}}' | jsonptrget /a/b/1/x~1y

Prints 9.

Failure

echo '{"a":1}' | jsonptrget /missing
missing missing

Exit code is 1.
